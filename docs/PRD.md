# TENEBIRIS OFFICE — Product Requirements Document (PRD)
## Version 1.0 (Greenfield)

### 1. Overview
TENEBIRIS OFFICE is a Virtual AI Workforce Operating System combining a Dark Gothic Occult Isometric Pixel Art environment with authoritative Hermes-native AI runtime orchestration.

Users manage AI workflows within an atmospheric 2.5D cathedral digital command center. The primary agent is **Mr Sunan** (Chief AI Orchestrator, Agent 001), representing the primary entry point to Hermes.

### 2. Core Personas & Roles
- **Supreme Orchestrator**: Mr Sunan (Agent 001), Supreme Command Chamber.
- **Hermes Runtime**: Sole authoritative AI execution engine for model reasoning, dynamic skills, and A2A delegation.
- **User / High Priest of Ops**: Sets strategy, issues master tasks via the Task Altar, reviews CAD blueprints, code diffs, and grants approvals.

### 3. Key Capabilities
1. **Isometric Pixel Art Virtual Office**:
   - Supreme Command Chamber (Mr Sunan)
   - Infernal Development Chamber (Software Engineering)
   - Forbidden Knowledge Archive (Research, Documents)
   - Shadow Rendering Studio (CAD, Visual Production)
   - Obsidian Infrastructure Chamber (DevOps, Cloud)
   - Council of Agents (Collaborative A2A Chamber)
2. **Hermes Native Integration**:
   - Capability Matrix verification (SUPPORTED, PARTIALLY SUPPORTED, etc.)
   - Dynamic Skill Discovery & Synchronization
   - Single source of truth: Hermes for AI execution; Tenebiris for visual layout, workstation states, and audit trails.
3. **Interactive Workstations**:
   - Live Coding Preview (syntax highlighted, diffs, test logs)
   - CAD Render Output (2D vector floorplans with dimensions, DXF/PDF/PNG exports)
   - Task Execution Terminal (step-by-step logs, live statuses)
   - Agent Communication (A2A message flow, approval requests)
   - Role Forge & Skill Builder (dynamic role crafting based on discovered skills)
4. **Task Altar & Workflow Builder**:
   - State machine: DRAFT -> QUEUED -> ASSIGNED -> RUNNING -> WAITING_APPROVAL -> COMPLETED / FAILED / CANCELLED.
   - Ritual Flows with multi-agent dependencies and human-in-the-loop gates.
